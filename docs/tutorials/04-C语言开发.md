# 04 · C 语言开发

构建器生成的是**原生 Win32 API** 代码，不依赖 MFC/Qt/.NET，编译后是独立 EXE。

## 生成代码结构

切到「C代码」页可看到：

```c
#include <windows.h>
#include <commctrl.h>
...
LRESULT CALLBACK WndProc(HWND, UINT, WPARAM, LPARAM);
int WINAPI WinMain(...) {
    /* 注册窗口类、创建主窗口 */
    /* CreateWindow 创建所有组件：Button/Static/Edit/ComboBox/PROGRESS_CLASS */
    /* 消息循环 */
}
LRESULT CALLBACK WndProc(...) {
    /* WM_CREATE  -> on_init()      (窗口启动积木) */
    /* WM_COMMAND -> on_btn_N()     (按钮点击积木) */
    /* WM_CLOSE   -> on_close()     (窗口关闭积木) */
}
```

每个组件按工具箱 ID 段映射菜单 ID：按钮 1000+、输入框 2000+、复选 3000+、单选 4000+、进度条 5000+、下拉 6000+。

## 直接运行（内置 GCC）

在「C代码」页或「设计/积木」页点顶部 **运行**，构建器会：
1. 把生成代码写入临时目录 `main.c`；
2. 调用内置 `runtime\mingw64\bin\gcc.exe`；
3. 自动生成含 ET 版权的版本资源 `app_ver.rc`，用 `windres` 编译；
4. 链接：`-lgdi32 -lcomctl32 -lgdiplus -lshell32 -lshlwapi -lole32 -luuid`；
5. 生成并启动 `app.exe`。

## 手动编译（进阶）

若想自己编译，命令等价于：

```bat
windres app_ver.rc -O coff -o app_ver.o
gcc -O2 -mwindows -finput-charset=UTF-8 main.c app_ver.o -o app.exe ^
    -lgdi32 -lcomctl32 -lgdiplus -lshell32 -lshlwapi -lole32 -luuid
```

> `-mwindows` 生成无控制台的 GUI 程序；源码统一 UTF-8，故加 `-finput-charset=UTF-8`。

## 在文件模式编译任意 .c

切「文件」页浏览到磁盘上的 `.c` 文件，选中后点
**▶ 编译并运行文件 (C/Py/Java)**，即会用内置 GCC 就地编译出同名 `.exe` 并运行。
适合做算法练习、小工具实验。

## 手写代码回填设计器

你也可以直接在 C 代码区按规范手写 `CreateWindow(L"Button", L"文字", ..., x,y,w,h, ...)`，
点「同步代码」后构建器会解析组件并回填到画布。
