# 07 · 加密项目与打包发布

## .nep 加密工程文件

「文件 → 保存项目」可把整个工程存为 `.nep`：

- 内容：窗口标题 / 尺寸 / 背景、全部组件与属性、积木脚本、导入的文件清单。
- 加密：ET 引擎自研方案
  - 口令派生：**PBKDF2-HMAC-SHA256**，10000 次迭代，内部盐；
  - 对称加密：**ChaCha20**；
  - 文件头：8 字节魔数 `ETNEP1\0\0` + 12 字节 nonce + 32 字节校验 + 密文。
- 保存时弹出"输入加密密码（留空则不加密）"：
  - 填密码 → 加密存储；
  - 留空 → 明文存储。
- 打开时若检测到加密，会弹出"该项目已加密，请输入密码"，口令错误则拒绝加载。

## 打包为 EXE

顶部「打包EXE」（或文件菜单"打包为EXE与安装包"）流程：

1. 选择输出目录。
2. 构建器生成当前项目的 C 代码 `main.c`。
3. 用内置 MinGW GCC 编译，自动附加**版本资源**（CompanyName=ET、
   LegalCopyright=(c) ET 2024-2026、ProductName、FileVersion=11.0）与自定义图标。
4. 得到独立可执行文件（默认名 `ETCWindowBuilderApp.exe`，可在"打包设置"改名）。

## 打包设置

顶部「打包设置」可配置：应用名称、开发者(ET)、版本号、公司(ET Studio)、
版权信息、描述、图标(.ico)、单文件/单目录、是否显示控制台。

## 生成 NSIS 安装程序

在已安装 NSIS 的环境（本程序发行包的制作环境已含）点打包时，会额外生成
`ETCWindowBuilder-Setup-v11.0.exe`：

- 简体中文 MUI2 向导；
- 安装到 `Program Files\ET Studio\ETCWindowBuilder`；
- 创建开始菜单 / 桌面快捷方式；
- 写入"添加或删除程序"卸载信息（发行商 ET）；
- 内置完整 `runtime\`（MinGW / Python / JDK）与 `docs\` 学习文档；
- 提供完整卸载。

用户运行安装包后，**无需再装任何编译器或运行时即可直接编译运行 C / Python / Java**。
