# 08 · 内置工具链说明

为做到"安装完即可直接使用"，安装包在程序目录内置了三套绿色便携工具链，
程序优先调用内置工具，找不到时才回退系统 PATH。

## 目录布局

```
<安装目录>\runtime\
├─ mingw64\bin\      MinGW-w64 GCC 14.2 (posix-seh, msvcrt)
│   ├─ gcc.exe  g++.exe  windres.exe  ld.exe  as.exe ...
├─ python\           CPython 3.11 (含 tkinter, pip)
│   └─ python.exe  pythonw.exe
└─ jdk\              Eclipse Temurin OpenJDK 17
    └─ bin\javac.exe  java.exe  jar.exe ...
```

## 版本与用途

| 工具链 | 版本 | 用途 | 许可 |
|---|---|---|---|
| MinGW-w64 / GCC | 14.2.0 | 编译 C/C++ 为 Windows 原生 EXE | GCC 运行时库例外 |
| CPython | 3.11.9 | 运行 tkinter GUI 与脚本 | PSF License |
| OpenJDK (Temurin) | 17 LTS | 编译/运行 Java、Swing | GPLv2 + CE |

## 查找顺序

程序内 `etb_find_tool()` 的解析顺序：
1. `<程序目录>\runtime\...` 下的内置工具；
2. 系统 `PATH` 中同名可执行文件。

因此即使系统未安装任何开发环境，"运行 / 编译 / 打包"也能正常工作；
高级用户自行安装的新版本工具同样可被识别。

## 常用命令（手动）

在安装目录打开终端可直接使用，例如：

```bat
runtime\mingw64\bin\gcc --version
runtime\python\python.exe --version
runtime\jdk\bin\java.exe -version
```

编译一个 C 文件：

```bat
runtime\mingw64\bin\gcc -O2 -mwindows hello.c -o hello.exe ^
  -lgdi32 -lcomctl32 -lshell32
```

## 体积与精简

完整内置三套环境约 1GB 出头。如需更小体积，可删除用不到的语言目录
（例如不用 Java 可删 `runtime\jdk`），程序会在对应功能不可用时给出明确提示。

## 离线使用

所有工具均为本地文件，不依赖联网；首次"运行"也不会触发任何下载。
