# 02 · 可视化设计

## 添加组件

左侧「设计」页工具箱提供：

| 组件 | 说明 |
|---|---|
| 按钮 Button | 可点击，支持点击事件积木 |
| 标签 Label | 静态文字 |
| 输入框 Entry | 单行文本输入 |
| 复选框 Checkbutton | 多选 |
| 单选钮 Radiobutton | 互斥单选 |
| 下拉列表 Combobox | 可设置候选项（逗号分隔） |
| 进度条 Progressbar | 进度指示 |
| 图像 Image | 加载本地图片 |
| 星星 / 菱形 / 圆形 | 特殊形状的按钮 |

## 选择与移动

- 单击组件：选中（出现蓝色高亮框），右侧显示其属性。
- 按住拖动：移动位置，属性面板 X / Y 实时联动。
- 双击组件：快速修改文本。
- 右键组件：编辑文本、复制、删除、置顶 / 置底、切换形状（矩形/星形/菱形/圆形）。

## 属性面板

可编辑：文本、X、Y、宽度、高度、字号、背景色、前景色、形状。
- 颜色：点"选择颜色"打开系统取色器，或直接填 `#RRGGBB`。
- 下拉列表：在"选项"栏用英文逗号分隔，如 `北京,上海,广州`。
- 图像：点"选择图片"载入 png/jpg/gif/bmp；"绑定文件"可让按钮点击时打开指定文件。

## 窗口设置

顶部「窗口设置」可修改：窗口标题、尺寸（如 `800x600`）、背景颜色。
顶部 `- / + / 100%` 可缩放画布（50%–200%），仅影响设计预览，不影响最终程序。

## 层级

多个组件重叠时，用右键"置顶/置底"调整 Z 序，这也决定了生成代码中的创建顺序。
