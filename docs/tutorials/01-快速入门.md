# 01 · 快速入门

ETC WindowBuilder 是一款"拖一拖、拼一拼就能做出 Windows 程序"的可视化开发工具，底层用纯 C 语言写成，无需 Visual Studio。

## 1. 启动

- 安装版：从开始菜单或桌面快捷方式启动 **ETC WindowBuilder**。
- 绿色版：直接双击 `ETC-WindowBuilder.exe`。

安装版已在程序目录的 `runtime\` 内置编译器和运行环境，**装完即可编译运行，无需任何额外配置**。

## 2. 认识主界面

- 左侧：模式标签（设计 / 积木 / C代码 / Py代码 / 文件）+ 组件工具箱。
- 中间：窗口设计画布（仿 Windows 窗口外观）。
- 右侧：属性面板、项目文件列表、实时日志。
- 顶部工具栏：缩放、运行、打包EXE、同步代码、窗口设置、打包设置、帮助。

## 3. 第一个程序（3 分钟）

1. 在「设计」页点击工具箱里的「按钮」，画布上出现一个蓝色按钮。
2. 拖动它到合适位置；在右侧属性面板把"文本"改成 `点我`。
3. 切到「积木」页，双击左侧积木库：
   - 事件类 `#1 当 {} 被点击`（选择按钮0）；
   - 动作类 `#10 显示消息框 "{}"`（填入文字 `你好，ET！`）。
4. 回到顶部点 **运行**。程序自动生成 C 代码、调用内置 GCC 编译并弹出新窗口。
5. 在新窗口里点击按钮，即可看到消息框。

## 4. 切换语言

- 在「C代码」页点运行 → 编译为原生 Windows EXE 并运行。
- 在「Py代码」页点运行 → 用内置 Python(tkinter) 运行同样的界面。

同一份设计可以同时得到 C 与 Python 两套实现，这就是"三向同步"。

## 5. 保存

「文件 → 保存项目」把界面、积木、窗口设置一起存为 `.nep` 工程文件，可设置密码加密。
