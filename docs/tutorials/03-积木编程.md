# 03 · 积木编程

积木（Block）编程让你不写代码也能为界面添加行为。积木按类别着色：
事件（橙）、动作（蓝）、变量（绿）、逻辑（紫）、循环（青）。

## 积木库

左侧「积木」页列出可用积木，双击即添加到右侧脚本区。

### 事件（程序的入口）
- `#0 当窗口启动时`：窗口创建后执行一次。
- `#1 当 {组件} 被点击`：指定按钮被点击时执行。
- `#2 当窗口关闭时`：退出前执行。

### 动作
- `#10 显示消息框 "文本"`：弹出提示框。
- `#11 设置 {组件} 的文本为 "文本"`：动态改标签/按钮文字。
- `#12 打开文件 "路径"`：用系统默认程序打开文件（如 `C:\Windows\notepad.exe`）。
- `#13 打开网址 "URL"`：调用默认浏览器。
- `#14 退出程序`：关闭窗口。
- `#15 隐藏 {组件}` / `#16 显示 {组件}`：控制可见性。
- `#17 播放提示音`：系统提示音。
- `#18 等待 {毫秒}`：延时。

### 变量 / 逻辑 / 循环
- `#20 变量 {名} 赋值为 "值"`、`#21 变量 {名} 增加 {值}`。
- `#30 如果 {条件}` … `#31 结束如果`。
- `#40 循环 {次数} 次` … `#41 结束循环`。

## 编辑参数

在右侧脚本区双击某条积木，或选中后点"编辑参数"，在对话框中填入内容。
组件参数可直接选 `按钮0`、`标签1` 等名称。

## 组织脚本

- 选中积木后用"上移 / 下移"调整执行顺序。
- "删除"移除单条；"清空"重置整个脚本。
- 动作积木应放在某个事件积木之下，最终按所属事件生成 `on_init` / `on_btn_N` / `on_close`。

## 生成结果

切到「C代码」或「Py代码」即可看到积木被翻译成真实代码：
- C：写入 `WM_CREATE`、`WM_COMMAND` 分支、`on_btn_N()` 等函数。
- Python：写入 `on_init()`、`on_btn(idx)`。

例如"按钮0 点击 → 打开记事本"会生成：
- C：`ShellExecuteW(hwnd, L"open", L"C:\\Windows\\notepad.exe", ...);`
- Py：`os.startfile(r"C:\Windows\notepad.exe")`
