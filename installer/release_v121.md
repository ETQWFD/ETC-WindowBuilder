# ETC WindowBuilder 专业版 v12.1

在 v12.0 基础上，本版重点修复**窗口图标不显示**与**打包产物图标/版本/可运行性**，并把品牌署名统一为 ETC。版权 (c) ETC 2024-2026。

## 本次修复

1. **构建器左上角 / 任务栏图标不显示（核心）**：此前窗口类从未加载图标资源，导致标题栏、任务栏、Alt-Tab 全是系统默认空白图标。现统一图标资源 ID 为 100，在窗口类注册时用 `LoadImage` 分别加载大、小两种尺寸，并在主窗口创建后再发 `WM_SETICON`（ICON_BIG / ICON_SMALL）双保险。已在 Wine 实测，标题栏左上角正确显示蓝色 ETC 图标。
2. **打包出的 EXE 也没有图标、无法运行**：
   - 生成的用户程序模板同样补上窗口类大/小图标加载与 `WM_SETICON`；
   - 打包资源（`.rc`）图标 ID 由原来的 2 统一为 100，与运行时 `LoadImage(MAKEINTRESOURCE(100))` 严格对应；
   - 未选图标时默认注入构建器自带 `app.ico`，并把图标复制为构建目录中的纯 ASCII 文件名 `app.ico`，规避 windres 在 C locale 下处理中文/空格路径失败；
   - 版本资源的开发者/公司/产品/版本/描述全部读取「打包设置」，并经 ASCII 过滤后再写入，杜绝 windres 截断非 ASCII 字符串导致的 `.rc` 语法错误。
   - 已端到端实测：内置 MinGW 的 windres + gcc 静态链接成功生成用户 EXE（159KB），`wrestool` 确认内含 group_icon(ID=100)、6 个尺寸图标与版本资源，程序可正常驻留运行、标题栏显示注入图标。
3. **品牌统一**：构建器与打包产物的开发者/公司/版权署名统一为 **ETC / ETC Studio**（此前版本资源里仍是 ET 或版本写死 11.0），文件与产品版本更新为 12.1；安装目录与开始菜单目录改为 `ETC Studio`。
4. 沿用 v12.0 的全部修复：NUL 字节、Python 缩进、代码换行与三向同步、编程猫式可拖拽积木、图片 GDI+ 加载、检查更新、打包文件占用（Permission denied）自动改名保存、安装包瘦身（约 103MB）。

## 安装包与运行时

- 完整离线安装包约 **103MB**，装完即用；安装后内置运行时约 546MB。
- `runtime\` 自带 MinGW-w64 GCC 14.2、CPython 3.11（含 tkinter）、jlink 裁剪的 OpenJDK 17，程序自动优先使用，无需配置环境。
